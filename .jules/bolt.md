## 2025-03-02 - Use requestAnimationFrame for UI Number Counters
**Learning:** Using `setInterval` for continuous UI animations (like number counters in `StatsSection`) causes jank and forces main thread execution regardless of display refresh rate or tab visibility. Replacing it with `requestAnimationFrame` and timestamp-based delta calculations (e.g., `progress = Math.min((timestamp - startTimestamp) / duration, 1)`) enables buttery smooth animations that automatically pause in background tabs, saving CPU and battery.
**Action:** When creating or reviewing components with continuous programmatic animations or interpolations over time, always use `requestAnimationFrame` instead of tick-based intervals (`setInterval` / `setTimeout`).
